# Galinum support

## Self-hosted product

Read the [documentation](https://docs.galinum.com) and the [self-host example](examples/self-host/README.md) first.

Open a GitHub issue for a reproducible defect in this repository. Include the commit, Node and Postgres versions, the smallest reproduction, and relevant logs with secrets removed.

Use a pull request for a tested fix. Follow [CONTRIBUTING.md](CONTRIBUTING.md).

## Galinum Cloud

This repository does not operate the managed Galinum Cloud service. Cloud billing, account, delivery-provider, backup, and operational requests belong in the support channel provided with the managed service.

## Security

Do not use a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md).
